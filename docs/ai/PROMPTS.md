# Complete sanitized AI prompt corpus

## Scope and classification

This index covers every project-specific Control Tower task packet in the retained
LockENS record, from the first ENSv2 vertical through final audit remediation, in
original order. Each linked file reproduces the complete available packet; only
explicitly marked private material is replaced. No packet is reconstructed or
summarized in place of available original wording.

The corpus contains **111 complete ORIGINAL / SANITIZED task packets** and one
additional record containing the **three exact original image-generation prompts**.
It does not claim to publish every conversational exchange, tool output, or unrelated
personal discussion. No unavailable material project-specific packet was identified
in the retained record.

## Redaction policy

Redactions use `[REDACTED: reason]` and cover personal filesystem paths, real
device/ADB identifiers, MAC-style hardware identifiers, private LAN configuration,
credential-bearing RPC URLs, private keys, tokens/OTP/session or account material,
personal email information, and raw proof/signature material. Public wallet
addresses, contract addresses, transaction hashes, protocol constants, test-only
placeholders, and reserved example hosts remain when they are project evidence.
